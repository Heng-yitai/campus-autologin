# 使用说明

## 怎么用

双击桌面上的「校园网一键登录」图标就行。不用打开浏览器，也不用先自己切 Wi-Fi ——
它自己会判断、自己会切。

- **已经在校园网里** → 直接认证
- **连的是别的网**（比如手机热点）→ 自动切到附近的校园网
- **校园网不在覆盖范围** → 自动切回你原来的网，并提示没搜到

> 程序会认多个 Wi-Fi 名字（比如宿舍一个、教学楼一个），不用手动告诉它你在哪栋楼。

---

## 界面是什么样

点下去之后，屏幕上方会出现一块**玻璃质感的面板**，状态文字原地更新：

```
正在检测网络 → 正在连接校园网 → 正在等待网络就绪 → 正在认证 → 结果
```

全程只有这一块面板，不会"弹一个消失、再弹一个消失"。
它是磨砂玻璃效果（背后画面被真实模糊），带圆角和投影，不抢焦点。

出结果后，成功停 **5 秒**、失败停 **9.5 秒**，足够看清；到点自己关掉，
出结果后点它一下也能立刻关。

面板上还有两样东西：

### 最近三条记录

灰字，显示哪次成功、哪次失败、失败原因一句话。
一眼就能看出"是不是一直卡在同一个错上"，不用去翻日志。

### 右上角「下线」按钮

点一下变「确认?」，再点一下才真的下线 —— 防止误触。

用途：把这台电脑的会话释放掉，好让手机登录（学校通常限制同时在线上限，一般 2 台）。
按钮点过一次之后面板会钉住不自动关，方便你确认；点别处仍然可以关掉。

## 第一次使用：录入账号

运行同目录下的 `setup_credentials.py`：

```bash
python setup_credentials.py
```

按提示输入：

1. **学号**（校园网账号，通常是学号）
2. **密码**（校园网登录密码，不是宽带密码）
3. **运营商**：`1` 电信 / `2` 移动 / `3` 联通

### 关于账号安全

密码用 Windows 的 DPAPI 加密后保存到 `config.dat`：

- 加密密钥与**当前 Windows 登录账户**绑定
- 把 `config.dat` 拷到别的电脑、或换个 Windows 账户，都解不开
- 密码任何时刻都不会以明文写入磁盘或日志

想改密码或换账号，重新跑一次 `setup_credentials.py` 即可，会覆盖旧配置。

> ⚠️ `config.dat` 不要发给别人 —— 虽然别人解不开，但也没必要给。

## 换宿舍、换教学楼要改什么吗

**什么都不用改。**

校园网门户地址是固定的，与你在哪栋楼无关；本机 IP 每次运行都会重新获取，
分到哪个网段都能用。

如果学校加了新的 Wi-Fi 名字，改 `campus_login.py` 里这一行：

```python
CAMPUS_SSIDS = ("6#SS-WiFi", "FYLG-WIFI")
```

有几个网名就往括号里加几项，程序会自动挑附近可见的那个。

## 守护进程（可选但推荐）

守护进程 `net_guard.py` 每 60 秒确认一次**真的能出网**，断了自动修复。

### 为什么要它

门户的会话会"无声失效"：服务端记着这台电脑还在线，网关那边早就不放行了。
在你发现"网页打不开"之前，它不会通知任何人 —— 守护进程就是替你看门的。

### 怎么用

| 操作 | 命令 |
|---|---|
| 启动 | 双击 `守护-启动.cmd` |
| 停止 | 双击 `守护-停止.cmd` |
| 看状态 | 双击 `守护-状态.cmd` |

### 它做什么 / 不做什么

**做：**

- 每 60 秒做一次**真实出网**探测（不是 ping 网关，那个永远通）
- 平时连着 2 次不通才动手（单次抖动不值得折腾）
- 动手时先注销本机 IP 的旧会话、再重新认证 —— 这才是僵尸会话的解法
- 修不好就退避（3 分钟 → 15 分钟），绝不反复刷账号

**不做：**

- 不在校园网里就不管（你连热点、在家时它安静待着）
- 你点过「下线」之后它暂停 30 分钟（避免刚释放的名额又被它抢回去）
- 不碰 Wi-Fi 开关、不碰 DNS、不改任何系统设置

### 开机自启

把你自己的快捷方式放进「启动」文件夹（`Win+R` 输入 `shell:startup`），
目标指向 `run_guard.vbs` 即可。

## 想让手机也能上网

学校的账号有"同时在线数"限制（通常 2 台）。如果手机登录时提示：

```
Rad:Limit Users Err
```

意思是这个账号的在线名额用完了 —— 通常是这台电脑还占着。

这时点面板右上角的「下线」按钮：它会立刻注销这台电脑的会话、把名额放出来。
（注销是按 IP 的，用的是 Dr.COM 协议自带的固定凭据，不会用到你的账号密码。）

⚠️ 注意两件事：

1. 下线后这台电脑会**立刻没网**，正在进行的网页 / 下载会断。
2. 下线请求必须在**连着校园网**时发出，所以不能"先连热点再下线"。
   点完再让手机去登录；电脑可以连手机热点恢复上网，或等手机用完后重新连校园网。

## 常见错误码

| 提示 | 意思 | 怎么办 |
|---|---|---|
| `Portal协议认证成功` | 成功了 | 没事 |
| `IP: x.x.x.x 已经在线` | 服务器记着你在线上 | 程序会自动核对真能不能上网 |
| `Rad:Passwd_Err` | **不是**登录密码错，是绑定的宽带账号密码错 | 去学校自助服务重绑（账号填手机号） |
| `Rad:UserName_Err` | 绑定的宽带账号不对 | 同上 |
| `Rad:Limit Users Err` | 在线设备数超了 | 点「下线」释放名额 |
| `系统忙!` / `ret_code: 3` | 认证服务器繁忙 | 不是你的问题，程序会自动等一会儿再试 |
| `账号或密码错误` | 真的错了，或你没连校园网就提交了 | 先确认连的是校园网 |

## 还是连不上怎么办

按顺序试：

1. **重启电脑**（点「重启」，不是「关机」再开 —— 快速启动等于没重启）
2. 设备管理器里找到无线网卡 → 禁用 → 再启用
3. Wi-Fi 列表里「忘记」校园网，重新连一次
4. 更新网卡驱动

具体的判断方法见主目录 `README.md` 的「故障排查」一节。
