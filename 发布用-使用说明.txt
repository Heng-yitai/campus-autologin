校园网一键登录 —— 使用说明
================================

【这是什么】
双击一下就连上校园网的小工具。不用打开浏览器、输账号密码、选运营商、
等它转圈。双击，一两秒完事。


【第一次用，做两件事】

  1. 把「校园网一键登录.exe」拖到桌面（或右键 → 发送到 → 桌面快捷方式）

  2. 双击它。第一次会弹出一个小窗口，让你填三样东西：
        · 校园网账号（学号）
        · 密码
        · 运营商（直接回车就是中国电信）
     填完按回车，窗口自动关掉。

以后每次双击，屏幕上方会出现一块玻璃质感的面板，上面写着
「正在检测网络 → 正在连接校园网 → 正在认证 → 登录成功」。
全程只有这一块面板，文字在原位更新，不会反复弹窗、也不会一闪而过。
出结果后成功停 5 秒、失败停 9.5 秒，点它一下可以立刻关掉。


【前提：你得是阜阳理工学院的】
这个工具是按阜阳理工学院的校园网做的（认证服务器 192.168.0.252、
Wi-Fi 名 6#SS-WiFi 和 FYLG-WIFI 都是学校特有的）。你是同校才能用。
别的学校需要改 3 处常量，详见仓库 README 的「适配自己的学校」。


【它会自己处理的情况】
  · 已经在校园网里       → 直接认证，一秒完事
  · 连着别的网（手机热点）→ 自动切到校园网 Wi-Fi，接上后再认证
  · 在宿舍还是教学楼      → 两个 Wi-Fi 名都认，自动挑附近能搜到的那个
  · 校园网不在覆盖范围   → 提示你没连上，不会瞎折腾
  · 启动后连点好几下     → 只跑一个，多余的自动忽略

换宿舍、换教学楼、IP 变了 —— 都不用管，它每次自己重新取。

顺带一句：如果系统里校园网的无线配置被"忘记"了（偶尔会发生），
它会自动补回去，不用你手动重新连。


【密码安全吗】
安全，而且是设计成"连你自己拷走都用不了"的那种：

  · 密码用 Windows 系统级加密（DPAPI）保存，加密密钥和你这台电脑的
    Windows 登录账户绑定。把 config.dat 拷到别的电脑、或换个账户登录，
    解出来就是乱码。
  · 程序只跟学校的认证服务器（192.168.0.252）通信，不往任何第三方
    服务器发数据。
  · 日志 login.log 只记时间和成功/失败，不记账号密码。


【出问题了怎么办】
  · 提示「没连上校园网」
      确认人还在学校、能搜到校园网 Wi-Fi，再双击一次。

  · 提示账号或密码错误
      删掉同目录的 config.dat，再双击一次重新填。

  · 提示「在线数已满」
      账号在其他设备上还挂着。点面板右上角「下线」，再让这台设备登录。

  · 双击没反应
      看同目录 login.log 的最后几行。

  · 杀毒软件报毒
      这是用 PyInstaller 打包的 Python 程序，容易被误报。
      加白名单即可（程序本身只做"连校园网"这一件事）。
