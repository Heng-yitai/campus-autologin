校园网一键登录 —— 使用说明
================================

【这是什么】
双击一下就连上校园网的小工具。不用开浏览器、不用输账号密码、不用选运营商。
双击，一两秒的事。

【第一次用，做两件事】

  1. 把「校园网一键登录.exe」拖到桌面，或者右键发送到桌面快捷方式

  2. 双击它。第一次会弹个小窗口，问你三样东西：
        · 校园网账号（学号）
        · 密码
        · 运营商（直接回车就是中国电信）
     填完按回车，窗口自己关掉。

之后每次双击，屏幕上方会出现一块玻璃质感的面板，文字在原位变：
「正在检测网络 → 正在连接校园网 → 正在认证 → 登录成功」。
从头到尾就这一块，不会弹一下消失了再弹一块。
出结果后成功停 5 秒、失败停 9.5 秒，点它一下能马上关掉。

【只有阜阳理工能用】
这是照我们学校的校园网做的。认证服务器 192.168.0.252，
Wi-Fi 名 6#SS-WiFi 和 FYLG-WIFI 也都是学校自己的。
别的学校要用得改三处常量，仓库 README 里「适配自己的学校」那节写了怎么改。

【它能自己处理的情况】
  · 已经在校园网里        → 直接认证，一秒完事
  · 连着手机热点          → 自动切到校园网，接上再认证
  · 在宿舍还是教学楼      → 两个 Wi-Fi 名都认，挑附近搜得到的那个
  · 附近根本没有校园网    → 告诉你没连上，不会瞎折腾
  · 连点好几下            → 只跑一个，多的自动忽略

换宿舍、换教学楼、IP 变了，都不用管，它每次自己重新取。

另外，如果系统里校园网的无线配置被"忘记"了（偶尔会），它会自己补回去，
不用你手动重连。

【密码安全吗】
挺安全的，是那种连你自己拷到别的电脑都用不了的设计。

密码用 Windows 的 DPAPI 加密，密钥跟你这台电脑的登录账户绑在一起。
把 config.dat 拷到另一台电脑，或者换个账户登录，解出来是乱码。

程序只跟学校认证服务器 192.168.0.252 说话，不往别的地方发东西。
login.log 里只记时间和成败，不记账号密码。

【出问题了】
  提示「没连上校园网」
      人还在学校、能搜到校园网的话，再双击一次。

  提示账号或密码错误
      删掉同目录的 config.dat，重新双击填一遍。

  提示「在线数已满」
      账号在别的设备上还挂着。点面板右上角「下线」，再登这台。

  双击没反应
      看同目录 login.log 最后几行写了什么。

  杀毒软件报毒
      PyInstaller 打的 Python 程序经常被误报，加白名单就行。
      它只干连校园网这一件事。
